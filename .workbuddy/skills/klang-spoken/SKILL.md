# 口语对应公式

用户在 WorkBuddy 里用口语问股票。不要让用户写公式。先对上 `server/spoken_catalog.json`，再扫描，把代码和名称回报回去。

## 工作流

在 Klang 仓库根目录执行：

```bash
python3 examples/spoken_scan.py --match "用户的原话"
python3 examples/spoken_scan.py --run "用户的原话"
```

1. `--match` 先看对上的是哪一条。对不上就停，改读 [klang-formula](../klang-formula/SKILL.md) 写一条新公式，用 `--limit 200` 试跑。不要猜一条没验证的公式直接扫全市场。
2. 对上了就 `--run`。涨停、跌停、炸板会自动改走 `tools/limit_up.py`（按涨停价封板）。其余走目录里的公式。
3. 调试时加 `--limit 200`。用户要的是结果时去掉 limit，扫完整股票列表。
4. 回复里给出：对上的说法、扫描了多少只、命中列表（代码、名称、数值）。命中很多时先给前 30 只，并说明总数。
5. 数据日期看输出或 `C` 的最后一根。缓存不是今天就说明「这是本地最后交易日的结果」，不要说成盘中实时。

`--formula` 会强迫涨停也走教学公式（大于 9.8%）。用户要的是涨停时不要加这个参数。

## 对照

说法写在 `server/spoken_catalog.json`。下表是给人对一下的，改表时两边一起改。匹配取**被问句包含、且更长**的那条：「MACD金叉」不会被「金叉」截走。

| 用户会说 | 对应 | 怎么执行 |
| --- | --- | --- |
| 涨停、封涨停、哪些票涨停 | 涨停 | `python3 tools/limit_up.py` |
| 跌停、封跌停 | 跌停 | `python3 tools/limit_up.py --down` |
| 炸板、触及涨停没封住 | 炸板 | `python3 tools/limit_up.py --broken` |
| 上涨、红盘、收红 | 今天上涨 | 涨幅 `[-1] > 0` |
| 下跌、绿盘、收绿 | 今天下跌 | 涨幅 `[-1] < 0` |
| 涨了 5 个点、大涨 | 涨幅超过 5% | 涨幅 `[-1] > 5` |
| 跌了 5 个点、大跌 | 跌幅超过 5% | 涨幅 `[-1] < -5` |
| 阳线、收阳 | 阳线 | `C[-1] > O[-1]` |
| 大阳线、长阳 | 大阳线 | 收阳且涨幅 > 5 |
| 均线多头、多头排列 | 均线多头 | `MA5 > MA10 > MA20` |
| 均线空头、空头排列 | 均线空头 | `MA5 < MA10 < MA20` |
| 站上 20 日线 | 站上 20 日线 | `C[-1] > MA(C,20)[-1]` |
| 跌破 20 日线 | 跌破 20 日线 | `C[-1] < MA(C,20)[-1]` |
| 5 日线上穿 10 日线、短期金叉 | 均线金叉 | `gold = CROSS(MA(C,5), MA(C,10))` 后判断 `gold[-1]` |
| 放量突破、放量上涨 | 放量突破 | 站上 20 日线且 5 日均量 > 60 日均量 × 1.5 |
| 倍量、量翻倍 | 倍量 | 今日量 > 昨日量 × 2 |
| 缩量 | 缩量 | 5 日均量 < 60 日均量 × 0.7 |
| MACD 金叉、DIF 上穿 DEA | MACD 金叉 | `dif[-1] > dea[-1] and dif[-2] <= dea[-2]` |
| MACD 死叉 | MACD 死叉 | DIF 下穿 DEA |
| 创新高、20 日新高 | 收盘创 20 日新高 | `C[-1] >= HHV(C,20)[-1]` |
| 创新低、20 日新低 | 收盘创 20 日新低 | `C[-1] <= LLV(C,20)[-1]` |
| 连涨 3 天 | 连涨 3 天 | `COUNT(C > C[1], 3) >= 3` |
| RSI 超卖、RSI 低于 30 | RSI 超卖 | `RSI(C,14)[-1] < 30` |
| RSI 超买、RSI 高于 70 | RSI 超买 | `RSI(C,14)[-1] > 70` |
| 布林上轨 | 触及布林上轨 | 收盘 >= 布林上轨 |
| KDJ 金叉、K 上穿 D | KDJ 金叉 | `k[-1] > d[-1] and k[-2] <= d[-2]` |
| 600 开头、沪市主板 | 600 开头 | `CODELIKE('600')` 且收阳 |
| ST、名字是 ST | ST 股票 | `NAMELIKE('ST')` 或 `NAMELIKE('*ST')` |

完整公式以 JSON 里的 `formula` 为准。`python3 examples/spoken_scan.py --list` 可以列出全部说法。

## 对不上时

只处理问句里**明确说出**的条件，缺的数字用表里的默认（20 日、5%、RSI 30/70）。然后按 klang-formula 的骨架写公式，先 `--limit 200`。

仍然对不上的，告诉用户现在能识别的就是 `--list` 里这些，并给出最接近的一条，不要编一只股票。

板块和概念本地表是空的，`INBLOCK` 不要用来回答「银行股」「人工智能」。名称前缀用 `NAMELIKE`，代码前缀用 `CODELIKE`。
